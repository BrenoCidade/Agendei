# Project Rules

- Never stage, commit, push, or open PRs including documentation files unless the user explicitly asks for it.
- Treat documentation as any file under `.planning/`, `docs/`, and standalone project docs such as `PROJECT.md`, `REQUIREMENTS.md`, `ROADMAP.md`, `STATE.md`, `CONTEXT.md`, and `DISCUSSION-LOG.md`.
- This is a workflow rule only. Do not add these files to `.gitignore` unless the user explicitly requests that change.
